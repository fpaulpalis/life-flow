Life-Flow is a web-based platform designed to manage user information and provide separate login access for users and administrators.

# Description
Life-Flow is a PHP-based website with MySQL integration that allows users to register and log in, and gives 
administrators access to manage user data. It features a user-friendly landing page, secure login systems, and a 
database-driven backend.

# Setup Instructions
Follow these steps to set up Life-Flow on your local machine:
1. Move Project Folder
Move the entire Life-Flow folder into the htdocs directory of your XAMPP installation. 
> Example path: `C:\xampp\htdocs\Life-Flow`

2. Start XAMPP Services
   - Open the **XAMPP Control Panel**
   - Start both **Apache** and **MySQL** services
4. Create Database
   - Open phpMyAdmin from the XAMPP Control Panel.
   - Create a new database named `life_flow`.
   - Import the `life_flow.sql` file located inside the project folder to set up the database schema and data.
6. Access the Website
   - Landing Page: `http://localhost/Life-Flow/index.php`
   - Admin Login: `http://localhost/Life-Flow/admin_login.php`
